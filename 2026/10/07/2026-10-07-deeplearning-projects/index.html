两个深度学习小实践：遥感变化检测 & 手写数字识别

这学期跟着课程完整跑了两个深度学习项目：一个是遥感影像的变化检测，一个是经典的 MNIST 手写数字识别。模型代码都是老师提供的现成工程，我没有从零写网络，主要是把环境配好、数据放对，把训练、评估、可视化整条流程在自己机器上跑通一遍。这里记录一下过程。

一、遥感变化检测：SNUNet-CD

1. 任务是什么

变化检测（Change Detection）就是给你同一地区两个不同时相的遥感影像（T1、T2），让模型标出”哪些地方发生了变化”。它在城市扩张监测、灾害评估、土地利用调查里用得很多。

课程给的工程是 SNUNet-CD（Siam-NestedUNet），出自论文 SNUNet-CD: A Densely Connected Siamese Network for Change Detection of VHR Images（IEEE GRSL 2021）。它的核心思路是：

  • 孪生（Siamese）结构：T1、T2 两幅图共享同一套权重各自提特征；
  • UNet++ 密集连接：把嵌套、密集跳跃连接融进编解码结构，让深浅层特征融合得更好；
  • 最后输出一张和原图等大的二值图，白色代表”变化”，黑色代表”未变化”。

2. 网络结构

整个网络是一个全卷积的编解码结构，左侧是双分支的共享编码器，右侧逐级上采样恢复分辨率，并用密集跳跃连接把对应层的特征拼回去。

3. 数据集与训练配置

用的是 CDD（Change Detection Dataset）的一个子集，按 train / val / test 划分。关键配置如下：

项目 设置
输入裁剪 256 × 256
batch size 2
初始学习率 1e-3
训练轮数 100 epoch
损失函数 hybrid（BCE + Dice 类混合损失）
GPU 单卡

4. 实验结果

在验证集上跑满 100 个 epoch 后，主要指标大致是：

指标 数值
OA（总体精度） 98.31%
Precision 75.59%
Recall 71.19%
F1-score 72.05%
验证损失 0.317

说明：因为变化区域在整张图里占比很小，类别极度不平衡，所以即使 OA 接近 98%，F1 也只有 72% 左右——单看 OA 会高估效果，做这类任务一定要盯 F1 和 Recall。

二、手写数字识别：MNIST

1. 任务是什么

这个就经典了——给一张 28×28 的灰度手写数字图，模型判断它是 0～9 中的哪一个。虽然简单，但把数据划分、网络搭建、训练、评估整条链路走一遍，理解会扎实很多。

2. 网络结构

配置：batch size = 320，训练 20 个 epoch，优化器 Adam（lr=2e-5），损失用 CrossEntropyLoss。从训练集里单独留出 1000 张图片只用于测试、不参与训练，避免”自欺欺人”。

4. 额外的收获：从零手写一个网络

除了直接调 PyTorch，我还在 自定义nn/ 目录里不依赖框架，自己实现了一套最小的神经网络：

  • layer.py / model.py：全连接层的前向传播；
  • loss.py：交叉熵损失；
  • structured_param.py：参数管理；
  • optimizer.py：SGD/Adam 式更新；
  • maths.py / initializer.py：激活函数、参数初始化；
  • 关键是自己手写了反向传播的梯度推导。

这部分不追求精度，主要是把”前向算输出 → 反向算梯度 → 优化器更新参数”这条链路亲手写一遍，对反向传播的理解比直接调 loss.backward() 清楚多了。

三、小结：这套代码是怎么跑起来的

两个项目都是老师给的现成工程，我没有从头写模型，主要工作是把环境搭好、数据放对、把流程跑通。关键步骤记录如下：

  1. 环境准备：装好 Python 3.10、带 CUDA 的 PyTorch，以及 opencv-python、tqdm、tensorboardX、scikit-learn 这些依赖；
  2. 数据就位：遥感把 CDD 子集按 CDData/subset/{train,val,test} 的目录结构放好；MNIST 直接用工程里带的 .npy 数据文件；
  3. 改配置：在 utils/parser.py（或命令行参数）里改好数据路径、patch size、batch size、训练轮数；
  4. 训练：python train.py 开跑；中途断点可以用 resume_train.py 从最近的 checkpoint 接着训；
  5. 出结果：python eval.py 算 Precision / Recall / F1 / OA，python visualization.py 把预测掩码输出到 output_img/。

过程里踩的坑也记一下：

  • 遥感那个训练到后期 torch.save 报磁盘写入失败，是 tmp/ 里堆了太多 epoch checkpoint 把 C 盘塞满了，及时清理即可；
  • 变化检测正负样本极不平衡，别看 OA，要盯 F1；
  • MNIST 单独留出 1000 张测试集不参与训练，否则准确率会虚高。

整体跑下来最大的收获不是调模型，而是把”数据 → 训练 → 评估 → 可视化”这条链路在自己机器上完整走了一遍。
